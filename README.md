# shannon.ir.intel.com

A WordPress site for the Intel Shannon, Ireland campus intranet.

## Contents

- A full WordPress installation (`wp-admin`, `wp-includes` and the
  root PHP files).
- `wp-content/themes`: the Twenty Thirteen, Twenty Fourteen and Twenty
  Fifteen themes.
- `wp-content/plugins`: plugins including Simple LDAP Login,
  TablePress, MaxGalleria, Responsive Lightbox, Responsive Menu, TinyMCE
  Advanced and a Joomla to WordPress importer.
- `web.config` for hosting on IIS.

## Tech

- PHP and WordPress
- MySQL

## Running

Host the folder on a web server with PHP and MySQL and set the database
details in `wp-config.php`.
